## Dormin Split Keyboard

Dormin is a 42 — 36 keys split keyboard, inspired by some awesome keyboards that I've used and loved. The main goal is to create a customizable keyboard with optional features, but still as minimal as possible regarding the design.

### Must have specs

- Wireless Ble.
- Ultra low-profile build (<= 7mm).
- Low-profile switches and keycaps.
- Compatible with MX-Standard and the Gateron KS33/3.0 Low-Profile switches & Choc V2.
- Huge battery life (1200mAh).
- Minimalist and industrial design.
- Aluminum case and plate.
- 4 different layouts trough breakaway parts.
- Split and "Unibody" layouts (Using Pogo pins)
- MX-Spacing
- Status LEDs

**Optional**

- EC12 Rotatory Encoder
- SD OLED screen or Nice!View

## Keyboard Layout Specification

*   **Total Keys:** 40 keys default layout (split 3x6+4).
    *   **Alpha matrix:** 6 columns x 3 rows per side.
    *   **Pinky Columns:** Outermost pinky column (`outer`) is configured with 2 keys (top row skipped). Inner pinky (`pinky`) has 3 keys.
    *   **Thumb Cluster:** 4 thumb keys per side (`t1` to `t4`).
*   **Breakaway Options (40 down to 34 keys):**
    *   The outermost pinky column (`outer`, 2 keys per side) can be snapped off.
    *   The innermost thumb key (`t4`, 1 key per side) can be snapped off (marked with `breakaway_thumb: true` tag).
    *   Depanelization points are aligned with standard **mouse bites** (perforations) placed between the breakaway sections.
